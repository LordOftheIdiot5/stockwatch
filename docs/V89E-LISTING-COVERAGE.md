# V89e listing coverage inventory (phase 1)
The existing price inventory is reused, so the denominator matches the curated UI rows rather than counting stock names as issuers. The generated data/listing-coverage-v1.json reports exact IDs, venue, identity evidence, observed price/date, explicit fundamentals, historical coverage, sector, description and archived metadata coverage. The audit is conservative: no fuzzy identity joins, no provider calls, no newly published prices, no inference that the 500 UI IDs represent 500 distinct securities or issuers. SEC cohort joins and cross-source security deduplication need separately validated identifiers. Use the missing-source queue for V89f–V89h. The scanner regenerates the inventory; release CI runs three tests and builds it against actual repository data. Counts reflect the inspected datasets, not universal coverage or rights.
