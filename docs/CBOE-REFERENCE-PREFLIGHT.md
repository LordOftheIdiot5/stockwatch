# Cboe Europe access preflight
Standard public CXE symbol file, schema documented in https://cdn.cboe.com/resources/participant_resources/BATS_Europe_Reference_Data.pdf. Probe reads in memory, counts live equity identities and matches exact ISIN plus primary MIC against existing research targets. No RIC, raw vendor rows or price values retained. The symbol file's reference_price and bats_prev_close can be stale or external-venue fallbacks, not reliably dated EOD closes; do not publish them as daily prices. Separate EOD delivery and reference redistribution review required. IEX HIST direct PCAP download page currently reports unavailable; use the already sent enquiry to establish official delivery. No price feeds activated.
