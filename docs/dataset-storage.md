# Dataset storage and reuse

The daily official refresh writes the existing latest JSON files and a compact data/research-index.json with individual series/dataset metadata, original period/unit/license, count, file SHA-256 and Git blob ID. Git already retains prior revisions; use these hashes and repository file history to identify snapshots. No separate duplicate public data tables are written. Research index links Energy Nordl's external catalog without claiming an active shared API. The index does not aggregate unlike counts or mix reference and quote coverage. Next: use index for search and source-specific loading; per-source incremental storage for rolling history; unified Leivro ingestion after rights and API authorization.

Optional private R2 archive uses existing scoped private bucket and independent STOCKWATCH_OPEN_DATA_ARCHIVE_ENABLED=true variable only after confirming the bucket remains private and budget is acceptable. Eight source-checked dataset IDs only (not arbitrary feeds); no raw exchange reports, Comtrade preview, news, SEC contact data, quote history or IMF data. Immutable compressed content-addressed objects and independent provenance receipts; unchanged data deduplicated, revisions retained. Existing exchange archive approval untouched. No R2 writes from feature branches. Git history is existing storage; R2 real-data writes not verified until enabled and run logs confirm. Versioned raw CSV strings retained for USGS. No new paid plans or public R2 access configured.
