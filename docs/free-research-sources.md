# Free official research sources

Initial collection scopes and terms are in scripts/free_research.py. Eurostat reuse attribution (dataset exceptions), SSB CC BY 4.0, SODIR NLOD 2.0, SEC public filings reuse with declared fair-access User-Agent, USGS parent 2026 CC0 inventory (child content not yet imported). Configure repository variable STOCKWATCH_SEC_USER_AGENT to your actual organization name and monitored contact email, not a secret. No key required. Comtrade preview bounded to one query per refresh; no original trade records stored or exposed. Daily main refresh publishes source-specific status and preserves prior data on failure; development branch probe does not publish. No exchange or freight quote license implied. Data display remains JSON link until dedicated research pages are integrated. Source date, period, retrieval timestamp and per-source rights must remain distinct. This is a starter scope, not complete world coverage.
