# Exchange capacity audit

One diagnostic request per supported Euronext market on PR/manual validation only, using existing public endpoints and byte limits. Raw ZIP and parsed rows remain in memory. Logs contain operational counts, sizes, UTC date bounds, schema and failure status only; no trade identifiers, price levels, volume, security names or downloads. A row is not necessarily an executed trade: revisions, duplicates, late publication, non-price-forming trades and empty files are not interpreted. An ISIN count is not a listing count; venues may differ. Successful audit does not imply complete coverage, permission to retain, derived distribution rights or official daily closes. No collection or retention setting changed. Nasdaq is still discovery-only. No additional subscriptions.
