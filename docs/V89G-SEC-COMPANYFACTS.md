# SEC Company Facts — V89g phase 1
Collect a bounded daily refresh for existing US research CIKs using the existing STOCKWATCH_SEC_USER_AGENT variable. No API key or new account. Selected US-GAAP tags in USD, USD/share and shares. Six-year initial lookback with subsequent additive retention. Original periods, filing dates, accessions, form and source link retained. Do not sum year-to-date and standalone quarters; no currency conversion, estimated ratios, or merging different tags. This is a dataset foundation, not yet a finished company-page UI or proof of redistribution rights for all issuer material. No full filings mirrored. Stop on 403/429; retain previous facts. Source: https://www.sec.gov/search-filings/edgar-application-programming-interfaces
