# Licensed reference price coverage (V29b)

The expanded 500-listing research universe currently contains 138 legacy scanner
listings and 362 reference records. Do not describe reference records as
market-data subscriptions. OpenFIGI is an identification service, not a quote feed.

## Release gate
Obtain an actual signed grant covering public display, raw redistribution in
publicly accessible JSON / Git history, long-term retention and derived
analytics. A display-only licence is insufficient for the current static
publishing architecture. Some vendors forbid redistribution of complete source
files; only normalized authorized observations may be imported. Do not store
vendor credentials, licence contracts or original provider files in this repo.
Review exchange, listing identity, currency, corporate-action treatment and
provider symbol for every mapping. The JSON grant is a record of human review,
not legal proof generated by the software.

## Import
Copy examples/reference-price-grant.example.json outside the repository and
populate it only after confirming all permissions. Prepare local CSV containing
listing_id,date,close,volume (volume optional). IDs are ref:MIC:symbol for the
75 research targets, and registry:MIC:FIGI for the 287 additional selections.

    python scripts/import_reference_prices.py /private/normalized.csv /private/reviewed-grant.json

The importer validates mapping membership, appends actual daily closes and
rejects conflicting historical values or incompatible source/rights metadata.
Initial imports require two dated observations; later updates may append one.
Inspect generated JSON and the associated licence before publishing. The
price-history page uses the same interactive calendar chart system as company
research pages. Consecutive recorded-close changes may span a gap; they are
not automatically one-session returns. These EOD observations are not mixed
with the legacy scanner's intraday or daily signal calculations.

## Pending provider work
A provider-specific scheduled adapter requires the contracted endpoint, exact
schema, rate limits, credentials stored privately, and documented entitlement.
No live feed is enabled by this release. For display-only rights, implement a
private server-side storage/display architecture instead of publishing raw JSON.
