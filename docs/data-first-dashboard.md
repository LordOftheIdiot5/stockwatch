# Data-first public dashboard

Use a single dated market snapshot (latest broadly covered prior date only if it contains more observations than the incomplete current session), including matching-date breadth, sector performance, heatmap and movers. Current coverage remains visible in one compact line with Data Health link; current attention uses current observations only. No fake prices or changes to data collection. Default map displays session observations; alternate coverage filters remain. Economic dashboard directly renders eight existing official series across currency, rates, inflation, industrial production and freight/connectivity, with actual dates, units and source-page links. No extra external API requests. No provider permission or deployment claim until tests pass. Dataset counts separate from equity data. Detailed licensed series coverage stays in Data Health/price history.
