# Private exchange collection and recovery

Euronext delayed reports: https://marketdata.euronext.com/data-reporting-service/trades-file . The published terms permit free internal use, with distribution subject to further conditions; the commercial project retains an explicit review gate. Nasdaq Nordic delayed equity files: https://tradereports.nasdaq.com/shares/trade-reports/post-trade . Its specific report portal says non-commercial use is free and other uses may incur fees. Nasdaq lists a 48h window on the portal, versus 24h in its general MiFID guidance; plan conservatively for 24h. Live Nasdaq report download links/schema and commercial project collection rights remain unverified, so discovery is metadata-only.

Use existing private R2 bucket and credentials. The archive job runs at 20:30 UTC weekdays for current and previous trading-day windows; at 06:30 UTC Tuesday–Saturday it retries previous trading day only. Deduplicates ZIP content; private receipts capture retrieval time and window, not session completeness. Failures isolated by market/window, abort on authentication/rate-limit statuses, nonzero exit on partial completion. No raw file in Git or public API. No new paid service. A second scheduled attempt does not guarantee recovery if data expires or GitHub Actions is unavailable.

Activation: confirm reviewed retention rights, set repository Actions variable STOCKWATCH_R2_RETENTION_APPROVED=true only after review, and optionally set STOCKWATCH_R2_EURONEXT_MARKETS to approved comma-separated venue codes (default OSL; supported OSL,PAR,AMS,BRU,DUB,LIS,MIL). Do not add markets beyond approval scope. Existing synthetic smoke test stays available without retention permission. Workflow dispatch with smoke_only=false executes approved collection. Public display, derived analytics redistribution and resale remain separately unauthorized. GitHub may incur runner costs depending on plan/limits, and R2 usage may incur storage/operation charges. No activation variable has been changed by this PR.
